Community fork by Sheldon (Aug 2026). OpenCC, fully offline. Toolbar: [b]Chinese Conversion[/b] / [b]简繁中文转换[/b] (Preferences lists [i]Chinese Conversion · 简繁转换[/i]). Not in the official calibre catalog yet — install from the zip below.

[b]3.13.0 highlights[/b]

- The conversion log (and Comments, when that option is on) now records the plugin version and which OpenCC dictionaries were used, so you can tell later whether a new plugin or dictionary update is worth converting again.
- Keyboard shortcut no longer opens the conversion window a second time after you close it.
- The conversion window looks at the book’s text and layout. When the result is clear enough, it shows a short note: Simplified or Traditional, and horizontal or vertical.

[b]From 3.2.0[/b] (if upgrading): library [b]main toolbar[/b] action — Preferences → Toolbars & menus → The main toolbar → add [b]Chinese Conversion[/b]. UI: EN / 简中 / 繁中 (TW·HK). Converts to a [b]new[/b] library book; original unchanged.

[b]Install[/b]

1. Optional: [code]calibre-customize -r "Chinese Conversion · 简繁转换"[/code]
2. Preferences → Plugins → Load from file → [b]chinese_text_conversion-3.13.0.zip[/b]
3. Restart calibre; add the toolbar button if needed.

Requires calibre 6.0+. Attached: [b]chinese_text_conversion-3.13.0.zip[/b]
