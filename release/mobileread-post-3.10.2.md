Community fork by Sheldon (Aug 2026). OpenCC, fully offline. Toolbar: [b]Chinese Conversion[/b] / [b]简繁中文转换[/b] (Preferences lists [i]Chinese Conversion · 简繁转换[/i]). Not in the official calibre catalog yet — install from the zip below.

[b]3.10.2 highlights[/b]

- Clearer Advanced options layout, with live [b]example previews[/b] when you change quotation marks, bilingual modes, and similar settings.
- New [b]Lighter output[/b] option: [b]Remove embedded font files[/b] — drops packed fonts for a smaller, faster book (readers use system fonts).
- New [b]Lighter output[/b] option: [b]Remove image files from the book[/b] — drops illustrations and the cover for a near text-only book (Vision OCR is disabled while this is on).

[b]From 3.2.0[/b] (if upgrading): library [b]main toolbar[/b] action — Preferences → Toolbars & menus → The main toolbar → add [b]Chinese Conversion[/b]. UI: EN / 简中 / 繁中 (TW·HK). Converts to a [b]new[/b] library book; original unchanged.

[b]Install[/b]

1. Optional: [code]calibre-customize -r "Chinese Conversion · 简繁转换"[/code]
2. Preferences → Plugins → Load from file → [b]chinese_text_conversion-3.10.2.zip[/b]
3. Restart calibre; add the toolbar button if needed.

Requires calibre 6.0+. Attached: [b]chinese_text_conversion-3.10.2.zip[/b]
