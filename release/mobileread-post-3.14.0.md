Community fork by Sheldon (Aug 2026). OpenCC, fully offline. Toolbar: [b]Chinese Conversion[/b] / [b]简繁中文转换[/b] (Preferences lists [i]Chinese Conversion · 简繁转换[/i]). Not in the official calibre catalog yet — install from the zip below.

[b]3.14.0 highlights[/b]

- New library books can get a [b]Script[/b] column (书写系统 / 書寫系統) so you can filter Simplified vs Traditional, including Taiwan and Hong Kong.
- The column heading follows calibre’s language: Script, 书写系统, or 書寫系統.
- Each book is tagged with both a language code (such as zh-Hant and zh_TW) and a Chinese label (such as 繁體中文_台灣).
- When “store conversion info in Comments” is on, the same tags plus a short note on images, fonts, and ebook version are added to Comments.

[b]From 3.2.0[/b] (if upgrading): library [b]main toolbar[/b] action — Preferences → Toolbars & menus → The main toolbar → add [b]Chinese Conversion[/b]. UI: EN / 简中 / 繁中 (TW·HK). Converts to a [b]new[/b] library book; original unchanged.

[b]Install[/b]

1. Optional: [code]calibre-customize -r "Chinese Conversion · 简繁转换"[/code]
2. Preferences → Plugins → Load from file → [b]chinese_text_conversion-3.14.0.zip[/b]
3. Restart calibre; add the toolbar button if needed.

Requires calibre 6.0+. Attached: [b]chinese_text_conversion-3.14.0.zip[/b]
