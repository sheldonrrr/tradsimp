Community fork by Sheldon (Jun 2026). OpenCC, fully offline. Toolbar: [b]Chinese Conversion[/b] / [b]简繁中文转换[/b] (Preferences lists [i]Chinese Conversion · 简繁转换[/i]). Not in the official calibre catalog yet — install from the zip below.

[b]3.3.0 highlights[/b]

- Smarter defaults for quotes/punctuation from text direction and locales; clearer library conversion logs.
- OpenCC dictionaries synced ([url=[https://github.com/BYVoid/OpenCC]BYVoid/OpenCC[/url]](https://github.com/BYVoid/OpenCC]BYVoid/OpenCC[/url]), [i]5d1eadd[/i], Jun 2026); HK/TW phrase configs updated.

[b]From 3.2.0[/b] (if upgrading): library [b]main toolbar[/b] action — Preferences → Toolbars & menus → The main toolbar → add [b]Chinese Conversion[/b]. UI: EN / 简中 / 繁中 (TW·HK). Converts to a [b]new[/b] library book; original unchanged.

[b]Install[/b]

1. Optional: [code]calibre-customize -r "Chinese Conversion · 简繁转换"[/code]
2. Preferences → Plugins → Load from file → [b]chinese_text_conversion-3.3.0.zip[/b]
3. Restart calibre; add the toolbar button if needed.

Requires calibre 6.0+. Attached: [b]chinese_text_conversion-3.3.0.zip[/b]
