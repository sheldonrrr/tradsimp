Community fork by Sheldon (Jul 2026). OpenCC, fully offline. Toolbar: [b]Chinese Conversion[/b] / [b]简繁中文转换[/b] (Preferences lists [i]Chinese Conversion · 简繁转换[/i]). Not in the official calibre catalog yet — install from the zip below.

[b]3.5.1 highlights[/b]

- Added optional macOS Vision OCR for images in whole-book conversion, with a confirmation prompt for large jobs and a hideable progress window.
- OCR runs in the background and is only offered when the local macOS Vision Framework supports it.
- Library conversion stays responsive and now logs the saved file name and path for each new book.
- Clearer Japanese Kanji labels, safer language checks, text-direction icons, and combo boxes that no longer change accidentally while scrolling.

[b]From 3.2.0[/b] (if upgrading): library [b]main toolbar[/b] action — Preferences → Toolbars & menus → The main toolbar → add [b]Chinese Conversion[/b]. UI: EN / 简中 / 繁中 (TW·HK). Converts to a [b]new[/b] library book; original unchanged.

[b]Install[/b]

1. Optional: [code]calibre-customize -r "Chinese Conversion · 简繁转换"[/code]
2. Preferences → Plugins → Load from file → [b]chinese_text_conversion-3.5.1.zip[/b]
3. Restart calibre; add the toolbar button if needed.

Requires calibre 6.0+. Attached: [b]chinese_text_conversion-3.5.1.zip[/b]
